# Mnemo

Mnemo is a study companion app built to help users organize study material, generate flashcards and quizzes, chat with an AI tutor, and track progress through a clean dashboard-style interface.

It is designed as a mock-first product, so the core experience works immediately without external services while still leaving room for private integrations later.

## What This Project Is

Mnemo is built to feel like a personal study workspace rather than a generic note-taking app. The core experience is centered around:

- organizing study materials and subject progress
- generating flashcards and quizzes from content
- chatting with an AI tutor for help and explanations
- tracking sessions, goals, and overall study progress
- keeping the interface fast, visual, and easy to use

The app currently uses mock data for the full experience, which keeps the product easy to understand and lets the main user flow stand on its own.
